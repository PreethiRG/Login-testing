# Login Testing

## TC001: Valid Login
**Test Scenario:** Verify login with valid credentials.

**Steps:**
1. Open the login page.
2. Enter valid credentials.
3. Click Login.

**Expected Result:** The user should log in successfully.

## TC002: Invalid Password
**Test Scenario:** Verify login with an invalid password.

**Steps:**
1. Open the login page.
2. Enter a valid username and an incorrect password.
3. Click Login.

**Expected Result:** The application should display an appropriate error message.

## TC003: Empty Login Fields
**Test Scenario:** Verify login with empty username and password fields.

**Steps:**
1. Open the login page.
2. Leave both fields empty.
3. Click Login.

**Expected Result:** The application should display appropriate validation messages.
